# Build-along guidance

Start with README.md, KNOWN-ISSUES.md and CHECKLIST.md. Treat this as a documented personal build, not a certified kit. Preserve the three-file sketch structure. Keep bench and PCB pin maps explicit. Use actual measurements, manufacturer specifications and the exact connector/footprint being used. Never claim physical verification from a code test. KiCad files must be edited through KiCad or a validated CAD tool, not raw text replacement. Do not publish device backups, EEPROM dumps, credentials or family media.
